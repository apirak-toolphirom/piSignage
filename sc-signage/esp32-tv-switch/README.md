# ESP32 ตัดไฟทีวีตามตาราง — SC Signage

ให้ ESP32 เปิด/ปิดไฟ AC ที่เข้าทีวีตามตารางเวลาเดียวกับที่ตั้งในหน้า **Groups → เปิด/ปิดจอตามเวลา**
ทำงานโดย ESP32 ถาม server ทุก 30 วินาทีว่าตอนนี้ทีวีควรเปิดไหม แล้วสั่งรีเลย์

## อุปกรณ์

| อุปกรณ์ | หมายเหตุ |
|---|---|
| ESP32 dev board | ~80฿ |
| โมดูลรีเลย์ 1 ช่อง 5V | หน้าสัมผัสทน 10A/250V (ทีวีกิน ~1A) ~25฿ |
| สายไฟ AC + กล่องหุ้ม | เดินสาย 220V ให้มิดชิด |
| ไฟเลี้ยง 5V | ดึงจากพอร์ต USB ของกล่อง AIS หรืออะแดปเตอร์ 5V แยก |

> ไฟ 5V จาก USB ของกล่องใช้ **เลี้ยง ESP32 + คอยล์รีเลย์** เท่านั้น ไม่ได้เป็นตัวตัดไฟ — ตัวที่ตัดคือหน้าสัมผัสรีเลย์ที่คุมไฟ AC 220V

## การต่อสาย

```
ESP32 GPIO26 ──────────► IN   (โมดูลรีเลย์)
ESP32 5V/VIN ──────────► VCC
ESP32 GND    ──────────► GND

ไฟ AC 220V เส้น L (Line) ─► COM (รีเลย์)
รีเลย์ NO (Normally Open) ─► ไปเข้าปลั๊กทีวี (เส้น L)
เส้น N (Neutral) ต่อตรงเข้าทีวีตามปกติ
```

ใช้ขั้ว **COM + NO** เพื่อให้ "ไฟดับ" เมื่อ ESP32 ไม่ทำงาน (ปลอดภัยกว่า)

## ติดตั้งเฟิร์มแวร์ (Arduino)

1. Arduino IDE → ติดตั้งบอร์ด ESP32 (Boards Manager: "esp32 by Espressif")
2. เปิด `esp32-tv-switch.ino` แก้ค่าด้านบน:
   - `WIFI_SSID`, `WIFI_PASS`
   - `HOST` = ชื่อ server `scsignage.local` (หรือใส่ IP ตรงๆ ก็ได้) · `PORT` = 3000
   - `GROUP_ID` = ไอดีกลุ่มของจอ (ดูในหน้า Groups หรือใช้ `gdefault` สำหรับกลุ่มค่าเริ่มต้น)
   - `RELAY_ACTIVE_LOW` = ถ้ารีเลย์ทำงานกลับด้าน (ทีวีดับตอนควรเปิด) ให้สลับค่า
3. เลือกบอร์ด "ESP32 Dev Module" → Upload
4. เปิด Serial Monitor (115200) ดูว่าเชื่อม WiFi และอ่านค่าได้

> ถ้าใช้ Home Assistant/ESPHome อยู่แล้ว มีไฟล์ `tv-switch.esphome.yaml` ให้แทน

## พฤติกรรม

- อ่านค่า `1`=เปิด `0`=ปิด จาก `GET /api/tv/<groupId>?fmt=text`
- ต้องได้ค่าใหม่ซ้ำ 2 ครั้งก่อนสลับรีเลย์ (กันกระพริบตอนเวลาคาบเกี่ยว)
- ติดต่อ server ไม่ได้ = คงสถานะเดิม ถ้านานเกิน (10 ครั้ง ~5 นาที) จะเปิดทีวีไว้ (`FAIL_SAFE_ON`)
- ตั้งตารางที่ไหน: หน้า **Groups → เปิด/ปิดจอตามเวลา** ของ server — ตารางเดียวคุมทั้งจอดำและไฟทีวี

## endpoint ที่เพิ่มในเซิร์ฟเวอร์

```
GET /api/tv/<groupId หรือ playerId>           -> {"group":"...","on":1,"tvEnabled":true}
GET /api/tv/<groupId>?fmt=text                -> "1" หรือ "0"
```

ไม่ต้องล็อกอิน (เปิดให้ ESP32 เรียก) เปิดเผยแค่สถานะเปิด/ปิด

## ใช้ชื่อแทน IP

server ประกาศชื่อผ่าน mDNS เป็น `scsignage.local` (เปลี่ยนได้ด้วยตัวแปรแวดล้อม `MDNS_NAME`)
- **ESP32** ใช้ `scsignage.local` ได้เลย (เฟิร์มแวร์ resolve เองผ่าน mDNS) — ไม่ต้องรู้ IP และ IP เปลี่ยนก็ยังทำงาน
- **กล่อง AIS (Android 7)** มักแปลชื่อ `.local` ไม่ได้ — ให้ใช้ IP ต่อไป หรือ (ก) ตั้ง DHCP reservation + ชื่อที่ router / DNS ของหน่วยงาน แล้วใส่ชื่อนั้นในแอป หรือ (ข) แจ้งให้เพิ่มมDNS resolver ในแอป (ต้อง build APK ใหม่)
